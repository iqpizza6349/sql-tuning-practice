## 02.Simple Latest

### 1. 아무 직원 한 명만 가져오기
> 재직자(STATUS = 'ACTIVE') 중 아무 직원이나 딱 한 명만 조회한다.

조건:
* ORDER BY 절 사용 금지
* 어떤 직원이 조회되는 것은 중요하지 않음
* 결과가 1건이기만 하면 된다.

### 2. 가장 최근 수정된 직원
> `EMPLOYEE.MODIFIED_AT` 을 기준으로 가장 최근 수정된 직원 1명만 조회한다.

조회 칼럼:
* EMPLOYEE_KEY
* EMPLOYEE_NO
* EMPLOYEE_NAME
* MODIFIED_AT

### 3. 최근 수정된 직원 10명
> 앞선 2번을 확장해서 가장 최근에 수정된 직원 10명을 조회한다.
> 동일한 `MODIFIED_AT` 이 존재할 수 있다고 가정한다.

> NOTICE: 결과 순서를 항상 동일하게 만들려면 무엇을 추가해야 할지도 생각할 것.

### 4. 가장 최근 급여 변경 한 건
> 전체 `SALARY` 가운데 `START_DATE` 가 가장 최근인 급여 변경 건 하나를 조회한다.
> 단, 현재 급여만 조회하는 의미가 아니다.

### 5. 한 직원의 가장 최근 급여
> `EMPLOYEE_KEY = 100000` 인 직원의 급여 이력 가운데 가장 최근 한 건을 조회한다.

조건:
* `END_DATE IS NULL` 조건에 의존하지 않는다.
* `START_DATE` 만 가지고 데이터를 조회한다.
